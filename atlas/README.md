## Run locally

From the repository root, run `python -m http.server 8080`, then open `http://localhost:8080/atlas/`. Opening HTML as `file://` cannot load ES modules and source assets.

The English presentation translates UI text without changing source layer IDs or the inspector classification logic. Original drawings retain their original language and image resolution.

## Public boundary

The eighth plot is reserved. No confidential concept figures, proposals, prices, Upwork documents, raw DWG/SKP, original private club photos/videos or client file paths are included. Gallery source hashes are retained. The club geometry derivative removes outlying source placements and all embedded bitmap textures, and simplifies repeated high-density details for web performance; it is an inspection presentation with neutral materials, not a newly certified as-built or matched V-Ray render. `source-derivatives.json` records the public geometry transformations.

The navigation city and businesses are conceptual; residents and traffic are fictional. Presentation lighting is not a photometric design. Models and renders can represent different revisions; no measured acoustic performance is asserted.

## Add another project

Add a reviewed source-model GLB, a city LOD with `city-preview.json`, and a `catalog.json` with project-only gallery references under `assets/projects/atlas/<id>/`. Add a plot entry and unique `shareSlug` to `assets/projects/atlas/city.json`. Preserve provenance, inspect the geometry bounds and test desktop/mobile navigation before publishing. Keep raw/private evidence outside the public repository.

## Cinematic inspection and venue life

Opening a source project starts a 34-second close camera tour: daylight construction, structural orbit, roof reveal, then warm night interior details. Pause, scrub, replay or take manual control. Reduced motion keeps the initial view static until the visitor explicitly starts the tour. Roof and four exterior view cuts are independent; picking a source part also permits reversible hiding of that individual mesh or instanced component. These are presentation sections, not edits to the source architecture.

SAWYER uses room bounds for camera fitting. Source node 276 (Existing Structure) is retained as a hidden survey reference because it overlaps the presented bedroom/studio layout. The original registered plan appears during the plan stage; all source binary assets remain unchanged.

Alain is a private cinema / club in a luxury residential villa; Can Furnet is a private club in a luxury residential villa. The remaining studios are luxury residential projects. Club del Mar and Playa Soleil are commercial venues. Their crowds, entry queues and DJ announcements are fictional portfolio atmosphere, not real event listings or occupancy figures.
