# XXXIA STUDIO — Visual Production Engine

XXXIA STUDIO is the visual-production layer for the portfolio and engineering projects.

## Mission
Turn real project evidence — photographs, drawings, renders, controls, components and site video — into controlled visual narratives: stills, exploded views, technical storyboards, motion briefs and production-ready video jobs.

## Pipeline
```
references -> brief -> storyboard -> generation job -> QA -> archive -> project embed
```

## Rules
- Source material remains traceable.
- Generated imagery is labelled conceptual / generated.
- Real project facts are not replaced by invented facts.
- Motion jobs must define shot list, duration, inputs, output naming and provenance.
- Outputs are versioned in GitHub when file size and licensing allow it.
- Production providers are adapters; XXXIA STUDIO owns the brief, prompt, manifest and archive contract.
