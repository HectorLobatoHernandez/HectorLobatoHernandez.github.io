# CV hero · React Bits attribution

The first screen of `cv/dossier.html` is a React island whose interaction patterns are adapted from the following React Bits components:

- Waves — https://reactbits.dev/backgrounds/waves
- Particles — https://reactbits.dev/backgrounds/particles
- Lattice Loader — https://reactbits.dev/micro/lattice-loader
- Tech Text — https://reactbits.dev/text-animations/tech-text
- Dither Veil — https://reactbits.dev/animations/dither-veil
- Circular Carousel — https://reactbits.dev/components/circular-carousel
- Staggered Menu — https://reactbits.dev/components/staggered-menu

Upstream repository: `DavidHDev/react-bits`
Reviewed upstream snapshot: `63a008de65732d73010bd219d25d15c47739bb31`
License: MIT.

The portfolio implementation is deliberately adapted rather than copied as a full React Bits application: the existing GitHub Pages dossier remains static HTML, while the first screen mounts a dependency-light React 18 island. The current circular carousel reuses the existing authorised portrait with visual treatments; it does not claim those treatments are separate photographic shoots or generated professional portraits.
