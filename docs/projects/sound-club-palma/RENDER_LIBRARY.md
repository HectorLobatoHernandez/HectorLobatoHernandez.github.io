## Asset paths

Optimized render assets are expected in:

`assets/visuals/sound-club-renders/`

The page has fallback images for every registered render, so missing local assets do not create broken image slots.

## 3D policy

`venue-web-v3.glb` is retained as a technical inspection model and remains manual-load only.

The visual storytelling hierarchy is:

`RENDERS / CAROUSELS → TECHNICAL DIAGRAMS → OPTIONAL 3D`
