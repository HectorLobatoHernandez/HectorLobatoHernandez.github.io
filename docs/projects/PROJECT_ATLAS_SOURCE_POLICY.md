# Project Atlas — Source & Evidence Policy

This archive is built from Héctor Lobato's supplied project files. The portfolio layer is a derivative presentation; the source files remain the evidence base.

## Rules

- **No invented project imagery.** Primary visuals must be user-supplied project media or a clearly labelled derivative of a supplied technical source.
- **No invented as-built geometry.** Browser 3D can spatialize real media, but it must not claim to reproduce construction geometry unless a verified model supports it.
- **Evidence states stay separate:** MEASURED, CALCULATED, PREDICTED, DESIGNED, INSTALLED and COMMISSIONED are not interchangeable.
- **Confidential identities stay private** unless there is explicit authorization to publish them.
- **Passwords, ETS/KNX Secure material, credentials and private commercial data are never public.**
- **Manufacturer literature is supporting documentation**, not proof of installed performance.
- Where the archive contains only documents and no public-safe image, the Atlas remains documentary rather than fabricating a visual.
