operating system.

RHB STUDIO es la plataforma local-first para agentes, CAD, documentación, presupuestos, renders y automatización de proyectos. El runtime completo sigue en local, pero GitHub Pages incluye una demo funcional browser-only para enseñar Project Core, Survey/CAD, BOM, routing, documentación y QA.

● LOCAL RUNTIME

Demo pública funcional / runtime privado local

La demo pública funciona sin backend y guarda los cambios únicamente en el navegador. OmniRoute, OpenClaw, NEXO, CAD real y archivos privados siguen requiriendo el entorno local.
